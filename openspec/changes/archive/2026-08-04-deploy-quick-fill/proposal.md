## Why

部署操作页面每次部署都需要重新选择任务、服务器、填写版本号和构建号等参数。对于频繁部署同一任务到同一组服务器的场景，重复输入效率低下。通过本地缓存最近几次部署参数并支持一键回填，可以显著减少重复操作，提升部署效率。

## What Changes

- 部署操作页面新增「快捷填充」区域，展示当前所选任务最近 3 次部署的历史参数
- 每次点击「开始部署」时，自动将当前表单参数缓存到浏览器 localStorage
- 缓存按 taskId 分组，每个任务保留最近 3 条记录，超出自动淘汰最旧的
- 点击某条历史记录，一键回填表单（任务、服务器、版本号、Jenkins 构建号）
- 无历史记录时不显示快捷填充区域

## Capabilities

### New Capabilities

- `deploy-quick-fill`: 部署表单本地缓存与快捷填充能力，包含历史记录存储、列表展示、一键回填

### Modified Capabilities

- （无）

## Impact

- 前端：`frontend/src/views/Deploy.vue` — 新增快捷填充 UI 与 localStorage 读写逻辑
- 无后端变更、无 API 变更、无数据库变更
- 完全前端本地功能，不影响服务端
